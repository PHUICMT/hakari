Hakari, a quiet meter for Claude Code usage on the Windows taskbar

Every surface the app ships with, drawn at 1:1 Windows 11 scale: the taskbar widget in all templates and states, the flyout, the dashboard, settings, notifications and first run. Every name, address, path and number on this page is made-up sample data.

Target WinUI 3 · Windows App SDK Scale 100% · 48px taskbar Themes Light · Dark · follows Windows Locale EN · ไทย
Foundations

Color

One brand hue, ai-iro (藍色, indigo dye), on cool neutrals. Status colors are reserved for limits and alerts and never used as decoration. In the app, the accent can follow the Windows accent color (setting) and falls back to ai-iro.

Surface & ink

Swatches show the active page theme. Use the switch in the sidebar to compare.

Accent & status

Status maps to limit usage: normal below 80%, warning from 80%, critical from 95% (thresholds are user settings).

Data

Chart series in fixed order: output, cache write 1h, cache write 5m, cache read, input. Heatmap uses a 5-step ramp of the accent.

Taskbar text sits on the Windows taskbar, not on Hakari surfaces, so the widget uses its own fixed pair of palettes (taskbar light / dark) chosen by the Windows "app mode" and "Windows mode" settings, independent of the dashboard theme.

Foundations

Typography

Segoe UI Variable for everything the user reads, Cascadia Mono for format strings and model ids. All numbers use tabular figures so digits don't jitter as they tick. The brand mark 秤 is set in a mincho face and used only as the logo.

Taskbar widget

Anatomy

Windows 11 has no deskband API, so the widget is a borderless, non-activating window positioned over free taskbar space, left of the notification area by default (the red box in the request screenshot).

Live

The sample below receives a new value every 2.5 seconds and walks through normal, warning and critical, so the odometer (only the changed digits roll), tone change, ring ease, stop disc and pulse can be judged at real size. It stops while this tab is hidden, as the app does.

1
Ring22px, 3px stroke, left of the two lines. Track is faint ink, fill is the accent, warning or critical tone. Shows the most pressing limit by default. At 100% it turns into a stop disc.
2
Two-line stackPrimary 13px bold over secondary 11px. Fits 40px without clipping at 100–150% scale. Antialiased, no grid fitting; Thai lines in Leelawadee UI.
3
Status toneText and bar take the warning or critical tone only for the metric that crossed a threshold.
4
Hit area40px tall, hover fill 5% (light) / 7% (dark). Click opens the flyout, right-click the menu, wheel cycles views.

Ring and lines

The ring shows the most pressing limit unless the user picks one: a full weekly limit beats an empty 5-hour one. Lines follow the formats below; the reset is a countdown (h:mm) under 24 h, weekday + time beyond.

Ring states

A full limit (100%) is not drawn as a closed ring: it becomes a solid disc in the critical tone with a short white bar across the middle, a stop sign. The "5h + Week" ring choice draws two concentric rings: the outer one is the weekly limit (22px, 3px stroke), the inner one the 5-hour limit (2.5px stroke, 1.5px gap inside the outer). When the weekly limit is full, only the stop disc is shown. Each sample is at 1:1 and at 3×.

Taskbar widget

Several accounts

Every signed-in account is found on its own. With more than one, Settings → Taskbar → Several accounts picks how they share the taskbar. Sample accounts: Work (work@example.com, Team) and Home (home@example.com, Max 20x).

Side by side is the default. One block per account, each with its own ring and money, split by a faint 1px divider. At most 3 blocks; further accounts are left to the flyout.

Together keeps one block and one ring (the most pressing limit across all accounts), with a labelled line per account, most pressing on top.

Take turns shows one account at a time and switches every 8 s by default (Switch every: 4, 8, 15 or 30 s) with the same rise-in as a value change (cross-fade in Reduced, a plain swap when Off). Dots show which account is up.

Shown on Main display (default), All displays, or Chosen displays (pick monitors in Settings → Sources → Taskbar displays). Every taskbar shows the same layout.

Taskbar widget

Layout templates

Seven starting layouts. Every slot is editable in Settings → Taskbar, and power users can replace any template with a format string. Each template is shown on a light and a dark taskbar.

Taskbar widget

States

The widget never hides. When it can't show a live value it says why in as few characters as possible, and the tooltip gives the full reason.

Taskbar widget

Placement

Shown on Main display (default), All displays, or Chosen displays, left of the notification area. The widget re-measures when the taskbar moves, the DPI changes, Explorer restarts, monitors come and go or apps are pinned.

LG 27UL850 · secondary taskbar · All displays or Chosen

Centered icons If pinned apps grow into the widget's space, the widget switches to its compact template instead of overlapping.

Auto-hide taskbar Widget hides and shows with the taskbar. Full-screen apps hide it.

Fallback If the overlay can't attach (unsupported shell), Hakari shows the tray icon with digits instead and says so once.

Accessibility & motion

Contrast & color

Text ≥ 4.5:1 on every surface in both themes, including on the taskbar. Status is never color only: warn and critical also change the label ("Limit", "≈") or add a pill. High-contrast themes swap to system colors.

Keyboard & screen readers

Widget is reachable with Win+B then arrows (tray order). Its accessible name reads the full tooltip. Flyout traps focus, starts on the first account section, and Esc returns focus. Every chart has a table view.

Motion

Animations setting: Full, Reduced (short fades, no movement), Off (nothing moves, lowest power). Starts in Reduced when Windows "Animation effects" is off. No animation carries information on its own; the final state is always readable.
